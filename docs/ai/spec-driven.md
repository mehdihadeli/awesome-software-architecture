# Spec Driven

## Libraries

- [Fission-AI/openspec](https://github.com/Fission-AI/openspec) - Spec-driven development (SDD) for AI coding assistants.
- [github/spec-kit](https://github.com/github/spec-kit) - Toolkit to help you get started with Spec-Driven Development
- [mchawa/eidos](https://github.com/mchawa/eidos) - Git-native living specification engine unifying DDD, Arc42/C4 architecture, W3C design systems, test-bound invariants, and a local SQLite/AST knowledge graph for coding agents.
