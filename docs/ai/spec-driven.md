# Spec Driven

## Libraries

- [Fission-AI/openspec](https://github.com/Fission-AI/openspec) - Spec-driven development (SDD) for AI coding assistants.
- [github/spec-kit](https://github.com/github/spec-kit) - Toolkit to help you get started with Spec-Driven Development

## Tools

- [Ifiok](https://ifiok.archiet.ai) - Spec-driven development platform that compiles a plain-English spec into a scored ArchiMate 3.2 architecture blueprint, then generates production web and mobile code from it.
